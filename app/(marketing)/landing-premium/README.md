# Site Institucional Premium CliniGo

Acesse a landing page premium em: **`/landing-premium`**

## 🎨 Design Commitment: MEDICAL BRUTALISM

### Características Implementadas

✅ **Tipografia Massiva**
- Headlines de 200-300px (responsivo com clamp)
- Font display premium (Satoshi/Inter fallback)
- Hierarquia visual extrema

✅ **Paleta Verde Profundo + Teal**
- `medical-dark`: #0A4D3C (verde profundo)
- `medical-teal`: #14B8A6 (teal luminoso)
- `medical-emerald`: #10B981 (emerald brilhante)
- `slate-deep`: #0F172A (background escuro)

✅ **Grid Assimétrico Fragmentado**
- Não usa Bento Grid
- Cards em diferentes tamanhos
- Espaçamento intencional

✅ **Animações Premium**
- Scroll-triggered (fade-in + slide-up)
- Stagger animations (0.1s delay)
- Cubic-bezier premium (0.16, 1, 0.3, 1)
- Parallax sutil

✅ **Sombras Multi-Layer**
- `shadow-premium`: 3 camadas
- `shadow-premium-xl`: 4 camadas profundas
- `shadow-glow-teal`: efeito glow

### Componentes Criados

1. **`PremiumButton`** - Gradientes verde→teal, hover scale
2. **`PremiumCard`** - Bordas brutais, sombras profundas
3. **`Badge`** - 7 variantes (PIONEIRO, SEGURO, NATIVO, etc.)
4. **`ScrollReveal`** - Animações scroll-triggered
5. **`ParallaxLayer`** - Efeitos parallax sutis

### Seções da Landing

1. **Hero** - Tipografia massiva, grid background, gradient radial
2. **Features** - 6 cards premium com badges e ícones
3. **Social Proof** - Métricas + depoimento
4. **CTA Final** - Call-to-action duplo
5. **Footer** - Minimalista, duas colunas

### Tecnologias

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS (design tokens customizados)
- Framer Motion (animações)
- Lucide React (ícones)
